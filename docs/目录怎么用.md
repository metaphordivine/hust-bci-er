# 目录怎么用

目标：这个仓库只保留重要模型、统一评估口径、深度验证方法。  
原则：**组件复用 + 路线配置 + 统一评估 + 可追溯审计**。

## 顶层目录

目录名用英文，中文解释写在文档里，方便脚本、CI、import 和多人协作。

```text
hust-bci-er/
  configs/        # 配置：路线、数据集、评估协议
  src/            # 源码：可复用组件
  scripts/        # 稳定命令入口
  reports/        # 简短路线总结
  docs/           # 项目文档
  tests/          # 自动测试
  agent_protocols/ # 平台无关协作/审计流程
  .github/        # GitHub Actions 云端检查
  outputs/        # 本地训练/评估输出，不提交
  scratch/        # 临时探索脚本，默认不进主线
```

## src 目录

```text
src/hust_bci_er/
  config/          # route schema、组件注册表、配置校验
  contracts/       # 数据对象契约：sample、batch、prediction、manifest
  data/            # 数据读取、manifest、subject split
  preprocessing/   # EA、whitening、滤波、zscore
  features/        # 微分熵、bandpower、Hjorth、连接特征
  models/          # 模型实现
  adaptation/      # AdaBN、DANN、domain loss
  training/        # trainer、loss、sampler、callback
  inference/       # Top-4、crop1-5/random、score fusion
  evaluation/      # 指标、P1/P2/P3、worst crop stress test
  audit/           # no-leakage、artifact manifest、报告生成
```

## models 目录

模型不要堆成 `model_v2_final.py`。按层拆：

```text
models/
  backbones/       # EEGNet、Conformer、Deformer、SRFNet
  graph/           # LGGNet、adjacency、图输入
  heads/           # linear、MLP 等输出头
  factory.py       # 按 config 创建模型
```

## evaluation 目录

评估最容易乱，要拆开：

```text
evaluation/
  metrics.py       # BA、AUC、all-correct
  protocols/       # P1/P2/P3
  crop_policy.py   # crop1-5、random、worst 的评估调用
  topk_policy.py   # Top-4 后处理
  stress_tests.py  # worst crop 等压力测试
  report.py        # 生成 summary
```

注意：

```text
Top-4、crop1-5、random 的推理规则 -> inference/
worst crop stress test            -> evaluation/
```

## 配置必须可校验

每条路线只写 config，不复制大脚本。

```text
configs/
  routes/
    stable/
    candidates/
    experimental/
    deprecated/
  datasets/
  protocols/
```

route config 必须包含：

```yaml
route_id: ea_deformer
status: IDEA
dataset_version: train_v1
split_id: p1_seed42_fold0
seed: 42
input_window_sec: 10
preprocessing: [euclidean_alignment, zscore]
features: []
model:
  name: deformer_lite
adaptation: none
inference:
  top4: true
  crop_policy: single
evaluation:
  protocol: p1_repeated_group_kfold
  primary_metric: exact_single_crop_expected_BA
```

校验入口：

```bash
python scripts/validate_route.py configs/routes/experimental/ea_deformer.yaml
```

校验内容：

| 检查 | 目的 |
|---|---|
| `route_id` 唯一 | 防止覆盖实验 |
| 组件名必须在 registry | 防止拼写漂移 |
| `seed` / `split_id` 必填 | 保证可复现 |
| evaluation 协议合法 | 防止 P1/P2/P3 混用 |
| output_dir 自动派生 | 防止覆盖旧输出 |

## 路线生命周期

每条路线必须有状态：

```text
IDEA
SMOKE_ONLY
DIAGNOSTIC_ONLY
CANDIDATE
PROMOTED
REJECTED
ARCHIVED
```

总表放：

```text
reports/route_board.md
```

用于回答：

```text
这条路线还能不能信？
是候选、诊断、废案，还是历史保留？
最后一次可信结果在哪里？
```

每次运行都生成：

```text

```

至少记录：

```json

  "git_commit": "...",
```

## scripts 只放稳定入口

```text
scripts/
  train.py
  evaluate.py
  infer.py
  validate_route.py
  audit_route.py
  make_report.py
```

临时脚本放 `scratch/`，不要污染主线。

推荐统一命令：

```bash
python -m hust_bci_er train --route configs/routes/experimental/ea_deformer.yaml
python -m hust_bci_er evaluate --run outputs/ea_deformer/20260514_120000
python -m hust_bci_er audit --run outputs/ea_deformer/20260514_120000
```

## Agent Protocol

Agent 流程不写成 Codex 专用 Skill，而是平台无关协议：

```text
AGENTS.md
agent_protocols/experiment_audit.md
```

任何协作者、AI assistant、本地脚本、GitHub Actions 都按同一套命令判断：

```bash
python scripts/check_repo_conventions.py
python scripts/validate_route.py --all
python -m pytest tests -q
```

有实验输出时再跑：

```bash
python scripts/audit_experiment.py --route <route_config> --run <run_dir>
```

核心原则：

```text
协议负责说明流程；
scripts 负责返回 pass/fail；
tests 负责固化红线；
CI 负责云端复查。
```

## reports 只放简短总结

每条重要路线只提交一个：

```text
reports/<route_id>/<route_id>_summary.md
```

summary 固定包含：

```text
status
config path / hash
dataset / split / seed
protocol
Top-4 / no-Top4 / all-correct
decision
risk notes
reproduce command
```

详细 CSV、checkpoint、trial 级预测留在 `outputs/`，不提交。

## tests 必须覆盖红线

```text
tests/
  test_route_schema.py
  test_no_public_labels.py
  test_no_id_shortcut.py
  test_subject_group_split.py
  test_top4_group_size.py
  test_metrics.py
  test_public_inference_no_label.py
```

重点检查：

| 测试 | 目的 |
|---|---|
| public/private label 不被训练读取 | 防泄露 |
| subject_id / trial_id 不作为特征 | 防 ID shortcut |
| train/val/test subject 不交叉 | 防 subject leakage |
| 每个 subject 恰好 8 trials | 防 Top-4 错位 |
| public inference 不读取 `y_true` | 防伪装无监督 |

## 例子

AdaBN EEGNet：

```yaml
route_id: adabn_eegnet
preprocessing: [zscore]
model: {name: eegnet}
adaptation: adabn
evaluation: {protocol: p1_repeated_group_kfold}
```

EA + Deformer：

```yaml
route_id: ea_deformer
preprocessing: [euclidean_alignment, zscore]
model: {name: deformer_lite}
adaptation: none
evaluation: {protocol: p2_pseudo_public_holdout}
```

微分熵手工特征：

```yaml
route_id: de_rf
features: [differential_entropy, bandpower]
model: {name: random_forest}
evaluation: {protocol: p1_repeated_group_kfold}
```

Whitening + SRFNet：

```yaml
route_id: whitening_srfnet_eps1e3
preprocessing: [whitening_eps1e3]
model: {name: srfnet}
evaluation: {protocol: p1_repeated_group_kfold}
```

已迁移的干净核心：

```text
models/backbones/eegnet.py
models/backbones/conformer_lite.py
models/backbones/deformer_lite.py
models/backbones/srfnet.py
preprocessing/whitening.py
preprocessing/euclidean_alignment.py
features/bandpower.py
features/differential_entropy.py
features/hjorth.py
evaluation/exact_single_crop.py
inference/score_fusion.py
inference/high_value_routes.py
```

保留的去 C4 路线：

```text
old_whitening_no_c4
qkv_best_no_c4
```

它们只保留模型/分数融合结构，不包含 `c4_prior_component` 或 trial-prior。

没有迁移：

```text
checkpoint
outputs
public/private label
leaderboard feedback
C4/trial-prior route
滑窗增强 trick
```

## 协作规则

1. 新方法先放组件目录。
2. 新实验只新增 route config。
3. 所有 route config 必须先 validate。
4. 每次运行必须生成 manifest。
5. 重要结果只提交一个 summary。
6. 不提交 checkpoint、raw outputs、trial 级预测。
7. 不使用 public/private labels、leaderboard feedback、ID shortcut。
